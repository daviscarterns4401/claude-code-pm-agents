## What Claude Code PM Does

Claude Code PM is built for individuals and teams using Claude Code alongside GitHub for AI-assisted development and project management. It takes product requirements and organizes them into epics and actionable implementation tasks, then links that planning work to GitHub Issues for a shared view of progress.

Multiple specialized AI agents can work concurrently while the project retains its context from one session to the next. Git worktrees support isolated work streams, while progress records, audit information, and human-AI handoffs keep planning and delivery aligned.

- Convert product requirements documents into epics and implementation tasks
- Keep project epics and tasks synchronized with GitHub Issues
- Run multiple specialized AI agents across parallel work streams
- Preserve project information between separate Claude Code sessions
- Use Git worktrees to manage simultaneous development efforts
- Record project activity through a detailed audit trail
- Enable human review, collaboration, and transitions between people and AI agents

## Workflow

Claude Code PM can be used through the following delivery sequence:

1. Create or bring in a product requirements document.
2. Run the planning workflow to divide the PRD into epics and implementation tasks.
3. Sync those epics and tasks with GitHub Issues.
4. Select specialized AI agents for the relevant work.
5. Separate independent work using Git worktrees when useful.
6. Inspect agent results and manage human-AI handoffs.
7. Record progress and synchronize the current project status.
8. Produce a project report with the reporting commands.

This keeps product requirements, implementation activities, GitHub tracking, and project history connected throughout the development process.
